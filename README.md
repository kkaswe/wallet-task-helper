# 钱包任务助手

Android 无障碍任务助手，当前版本 **0.1.57**（versionCode 64）。面向荣耀钱包省钱任务页，提供任务扫描、体验计时、返回领取、安装台账及清理、视频任务和每日解锁计划。

## 工程形态

这是从已有个人应用恢复并持续维护的 **Smali / Android 资源工程**，不是完整的原始 Java 或 Gradle 工程。

- `app/smali`：实际参与 APK 构建的代码。
- `app/res`、`app/assets`、`app/AndroidManifest.xml`：资源和清单。
- `patch-src`：部分模块的 Java 源码与 Smali 适配代码。`soda-stubs` 是编译用桩，不能打包。
- `tests`：不含个人设备快照的合成数据回归测试。

**仅修改 patch-src 不会自动改变 APK。** 修改 Java 模块后需要使用 Android API、D8 和 baksmali 生成对应 Smali，再替换 `app/smali` 中的目标类。主体服务目前仍需直接维护 Smali。

## 当前行为

- 当地时间每天 05:00 后首次解锁触发；不会自行解锁手机。
- 支持连续两天体验、浏览应用、下载体验、第二轮重开及视频任务。
- 记录运行期间的新增应用，清理非次日任务应用；次日任务或归属待核对应用保留。
- 开始前保存媒体音量并归零，结束或停止后恢复。
- 锁屏暂停可在解锁后恢复；手动或异常暂停等待手动继续。
- 视频倒计时停滞 45 秒或播放达到 180 秒时，最多关闭 Wi-Fi 重试一次，结束后恢复原状态。正常流程不切换 Wi-Fi。
- 完成后发送结果通知并关闭浮窗，无持续通知。

## 构建

需要 Java 17 或更新版本、PowerShell 7，以及自行准备的 Apktool 2.11.1 JAR。

```powershell
$env:APKTOOL_JAR = 'C:\tools\apktool.jar'
# java 不在 PATH 中时指定 JAVA_EXE
$env:JAVA_EXE = 'C:\tools\jdk\bin\java.exe'
./scripts/build.ps1
./scripts/test.ps1
```

输出为 `dist/wallet-task-helper-unsigned.apk`。签名工具、签名证书和私钥不随源码分发；安装前请使用自己的密钥签名。自签包不能直接覆盖其他签名的已安装应用。

## 使用

安装签名 APK 后开启助手无障碍服务，打开钱包省钱任务页，使用浮窗开始任务。保持手机解锁和亮屏。自动计划及调试入口位于助手首页；视频补跑入口在调试页。

## 已知限制

- 页面文字、控件 ID、系统设置页及广告布局变化可能影响识别，需要适配后实测。
- 单元测试不代表完整真机流程通过；0.1.57 的超时自动切网完整链路尚未完成真机验证。
- 当前“本轮结束/今日已处理”包含部分失败的收尾情况，不等价于全部任务成功；请查看结果详情。
- 工程保留早期附加的汽水音乐工具代码，但当前维护重点为钱包模块。
